# ثبت‌نام و اشتراک AliPrompt

این نسخه از MySQL موجود پروژه استفاده می‌کند؛ سرویس پیامکی یا درگاه بانکی خودکار اضافه نشده است.

## فعال‌سازی ذخیره واقعی اطلاعات

۱. دیتابیس MySQL را در هاست خود ایجاد کنید و مقادیر DB_HOST، DB_PORT، DB_NAME، DB_USER و DB_PASSWORD را طبق .env.example در .env.local (برای لوکال) یا تنظیمات محیطی سرور وارد کنید. رمز یا فایل محیطی را در Git قرار ندهید.

۲. فایل database/schema.sql و سپس database/membership-migration.sql را در MySQL اجرا کنید. migration را فقط یک بار اجرا کنید. اگر نام دیتابیس متفاوت است، دستور USE را مطابق نام آن تغییر دهید.

۳. AUTH_SECRET باید یک مقدار تصادفی و قوی باشد. پس از تنظیم محیط، سرور را دوباره اجرا کنید.

## استفاده

- کاربران در /login با نام فارسی، شماره و رمز حداقل ۸ کاراکتری ثبت‌نام می‌کنند. شماره با پیامک تأیید نمی‌شود. پس از ثبت‌نام به /account منتقل می‌شوند.
- حساب جدید Free است. نام، شماره، تاریخ عضویت و وضعیت اشتراک در /admin نمایش داده می‌شوند؛ رمز فقط هش شده و در پنل قابل نمایش نیست.
- قیمت Pro برابر ۲۵۰٬۰۰۰ تومان است؛ شماره کارت و صاحب کارت در lib/membership.ts قرار دارند و در صفحه حساب نمایش داده می‌شوند.
- کاربر تصویر رسید تا ۳MB و کد پیگیری را ارسال می‌کند. رسید در MySQL ذخیره شده و فقط خود کاربر یا مدیر مجاز به مشاهده آن هستند.
- مدیر در /admin، بخش کاربران و اشتراک‌ها، واریز واقعی را از حساب بانکی بررسی می‌کند و رسید را تأیید یا رد می‌کند. عکس رسید به‌تنهایی اثبات واریز نیست.
- پس از تأیید، حساب Pro می‌شود. نشان از دیتابیس خوانده می‌شود، نه LocalStorage. صفحه حساب هنگام انتظار هر ۱۵ ثانیه وضعیت را به‌روز می‌کند.
- مدت اعتبار و امکانات انحصاری Pro هنوز مشخص نشده‌اند؛ این تغییر فقط وضعیت عضویت و تأیید پرداخت را اضافه می‌کند. قبل از فروش عمومی مدت و مزایای اشتراک را تعیین کنید.

## قبل از انتشار عمومی

کد ساده مدیر را تغییر دهید، HTTPS و محدودسازی تلاش ورود در reverse proxy/هاست فعال کنید و از دیتابیس (شامل رسیدهای خصوصی) پشتیبان بگیرید. استفاده از شماره موبایل بدون تأیید پیامکی اثبات مالکیت شماره نیست. نگهداری رسیدها و سیاست حریم خصوصی باید برای کاربران روشن باشد. MySQL برای این بخش لازم است؛ حالت فایل محلی فقط پرامپت‌ها را نمایش می‌دهد و کاربران یا پرداخت‌ها را ذخیره نمی‌کند.

# سفارش اکانت و رسید پرداخت

برای فعال‌کردن ثبت سفارش، یک‌بار فایل `database/orders-migration.sql` را در MySQL اجرا کنید. این فایل جدول سفارش‌ها و ایندکس‌های لازم را ایجاد می‌کند.

متغیرهای زیر باید فقط در `.env.local` روی سیستم خودتان یا Environment Variables سرویس Deploy قرار بگیرند:

```env
PAYMENT_CARD_NUMBER=شماره_۱۶_رقمی_کارت
PAYMENT_CARD_HOLDER=نام_صاحب_کارت
```

فایل‌های رسید به‌صورت `MEDIUMBLOB` داخل MySQL ذخیره می‌شوند و public نیستند. فقط مدیر واردشده می‌تواند رسید را از پنل مدیریت باز کند.

روند کار:

1. کاربر ثبت‌نام یا وارد حسابش می‌شود.
2. سرویس را انتخاب می‌کند و مبلغ را کارت‌به‌کارت انتقال می‌دهد.
3. شماره پیگیری و رسید را آپلود می‌کند.
4. سفارش با وضعیت «در انتظار بررسی» در `/admin` نمایش داده می‌شود.
5. مدیر رسید را مشاهده و سفارش را تأیید یا رد می‌کند.

فعال‌سازی اکانت باید فقط بعد از تأیید دستی پرداخت انجام شود.
